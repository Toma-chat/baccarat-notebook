# バカラ記録帳

React / TypeScript / Viteによる端末内完結の記録用PWAです。P=赤、B=青、T=緑、N=黄色。アカウント・API・サーバーDB・解析・ベット機能はありません。添付画像は今回の作業環境では確認できなかったため、仕様の配置を基準に実装しました。

公開先：https://toma-chat.github.io/baccarat-notebook/

ソース：https://github.com/Toma-chat/baccarat-notebook

## 起動とビルド

Node.js 22.12以上（推奨24）をインストールして、このフォルダーで実行します。

```sh
npm ci
npm run dev
```

本番用ファイルとテスト：

```sh
npm test
npm run build
npm run preview
```

`dist/`が公開対象です。HTMLをダブルクリックするfile://方式では利用できません。開発サーバーではオフラインキャッシュを作らず、本番ビルドのHTTPS配信（PC内のlocalhostも可）で有効です。

## 無料の静的ホスティングに公開

GitHub Pagesの例（公開リポジトリを利用）：

1. このソースをGitHubリポジトリに置きます。`node_modules`は含めません。
2. Settings → Pages → SourceでGitHub Actionsを選びます。
3. 同梱の`.github/workflows/pages.yml`をコミットし、Actionsの完了を待ちます。
4. Pagesに表示されたHTTPS URLをSafariで開きます。

`base: './'`のためリポジトリ名のサブパスにも対応します。GitHub Pagesの公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

別の静的ホスティングでは`npm ci && npm run build`をビルドコマンド、`dist`を公開ディレクトリに指定します。サーバー処理は不要です。ホスティングの無料枠・条件は各サービスで確認してください。

## iPadで使う

1. 公開したHTTPS URLをSafariで一度オンラインで開きます。
2. 読み込み完了後、共有 →「ホーム画面に追加」→「追加」。
3. ホーム画面のアイコンから起動します。初回キャッシュ作成後はオフラインでも入力・閲覧できます。
4. 機内モードでアプリをいったん閉じて再起動し、利用する端末で確認してください。

横画面（幅900px以上）はSafariの表示領域の高さに合わせて、主要な罫線・集計・入力を一画面に収めます。付加情報と選択解除は44px、結果入力は60pxを確保し、罫線の6行マスを自動縮小します。縦画面は縦スクロールで操作します。マスをタップすると詳細が開きます。タイは大路でも独立した緑〇として表示します。同じ結果は縦、P/B/Tの切替で次列に進み、補助罫線はタイを除いて計算します。

## 保存・バックアップ

集計欄にはP/B/Tと付加情報5種類を常時表示します。各集計をタップすると回数と割合を切り替えます。割合の分母は閲覧中シューの総ゲーム数（タイを含む）、小数点以下1桁です。0ゲームは0.0%になります。両ペアなどは重複して数えるため、付加情報の割合の合計は100%とは限りません。

- IndexedDBの`baccarat-notebook` → `state` → `data`にシュー別の全ゲームを自動保存します。保存成功後に画面を更新します。保存失敗は画面で通知し、登録した扱いにしません。
- 勝者・時刻・両ペア・N・ドラゴン7・パンダ8が元データです。罫線は毎回再計算します。
- 「設定」→「JSONを書き出す」でファイルにバックアップしてください。「JSONを読み込む」で形式を検証し、確認後に**既存データを保持して別シューとして追加**します。番号・IDを振り直すため、同じバックアップを再度読み込むと重複した履歴が追加されます。
- 保存先は端末・ブラウザ・サイトURLごとに別です。別端末への同期はありません。URLを変えた場合はバックアップから移してください。
- SafariのWebサイトデータ消去、プライベートブラウズ終了、OSの保存領域整理などでデータが失われる場合があります。定期的なJSON保存が必要です。ホーム画面版とSafari版の保存領域の扱いも実機で確認してください。
- 履歴は閲覧専用です。最新の記録中シューに戻るには「履歴」から「記録中」を選びます。
